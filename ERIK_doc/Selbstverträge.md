Sein eigener Reiter. Hier können Verträge mit sich selbst abgeschlossen werden; bestehende und legacy Verträge werden hier angezeigt.

Es können immer 3 Verträge gleichzeitig laufen. Festgelegt werden:

Konditionen: Was verlangt der Vertrag? Was ist ein Vertragsbruch?
Laufzeit: Dauer des Vertrags (mindestens 2 Wochen)
Aufwand: (Leicht: 0.5 Punkte, Mittel: 1 Punkt, Schwer: 1.5 Punkte)
Garantie, dass nach bestem ermessen die Regeln des Vertrags verfolgt werden und das Vertragsbruch die termination des Vertrags bedeutet
--> DATUM UND UNTERSCHRIFTSFELD

In der täglichen Reevaluation wird abgefragt, ob die Vertragskonditionen erhalten wurden. Wenn ja, werden die zu jedem Vertrag zugehörigen Punkte hinzugefügt. Wenn nein, dann wird der Vertrag gebrochen und aufgekündigt. Wird ein Vertrag auf diese Art gekündigt, dann wird eine vom Zeitpunkt des Vertragsschlusses ausgehende, einmonatige Sperre dieses "Vertrags-slots" verhängt. So soll verhindert werden, dass einfach ein neuer Vertrag abgeschlossen wird.

Läuft ein Vertrag durch erreichen der Vertragsdauer aus, wird das in der Planungsphase des letzten Tages erwähnt. Der Vertrag kann dann entweder verlängert, verändert oder gekündigt werden. Wird der Vertrag so gekündigt, wird keine Sperre verhängt.

Läuft ein Vertrag für einen Monat ununterbrochen, kann er zu einem "Legacy-Vertrag" upgegraded werden. Ein legacy vertrag verbraucht keinen der 3 Vertrags-Slots, liefert allerdings nur 20% der Punkte und muss trotzdem befolgt werden (Abfrage erfolgt ebenfalls in Planungsphase). So können Punkte-Boni aufgebaut werden, es müssen allerdings alle Verträge gepflegt werden. Es können täglich maximal 2 Punkte durch Legacy Verträge erwirtschaftet werden. Sollten mehr Punkte als 2 erwirtschaftet werden, dann soll das im Dashboard besonders angezeigt werden (durch eine Krone o.ä.)
