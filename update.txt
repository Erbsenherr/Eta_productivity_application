Features:
-Belohn-o-mat: Neuer Reiter "Belohn-o-mat". Hier können Langzeitbelohnungen erstellt werden (zB. "Ein gutes Steak für 50 Euro kaufen"). Diese können dann mit Punkte-Kosten versehen werden (zB. 25 Punkte). Eine Belohnung besitzt also einen Namen und eine Punktzahl. Optional kann eine (oder mehrere) Aufgaben an sie gebunden werden. Wenn das geschehen soll, kann der Nutzer den Button "Aufgabenbindung" anwählen. Dann öffnet sich ein Menü wiederkehrender Tasks, die angehakt werden können. Über dieses Menü kann auch eine neue wiederkehrende Task erstellt werden. Der Reiter ist wie folgt organisiert: Es gibt eine absteigende Liste, die länger wird, je mehr Belohnungen man sich erstellt (jeder Eintrag = eine Belohnung). Belohnungen können in ihrer Reihenfolge verschoben werden. Es wird immer nur die Belohnung abgearbeitet, die sich in Position 1 befindet. Der Mechanismus: Jeden Tag/Abend bei der Punktabrechnung werden alle an dem Tag erworbenen Punkte der Belohnung in Position 1 hinzugefügt (Abgezogene Punkte zählen nicht, es wird also jeder erworbene Punkt vor Abzug hinzugefügt). Visuell sieht das auf der "Belohn-o-mat" Seite dann so aus, dass der Erste Eintrag der Liste (ähnlich wie wenn man eine Task wegen höherer Macht absagt) langsam einfärbt. Es soll also (sofern Belohnungen eingerichtet sind) bei der Tagesabrechnung einen weiteren Tagesordnungspunkt geben, bei dem der Nutzer sieht, wie sich der Balken mit den Punkten auffüllt(Das soll außerdem von einem "Auffüll-Sound" begleitet werden, zumindest später)! Wenn der Balken die 100% Erreicht, soll ein Sound gespielt werden und dem Nutzer gratuliert werden, dass er seine Belohnung nun einlösen kann (Für Sound nimm erstmal Platzhalter). Wie gesagt kann der Nutzer die Reihenfolge der Belohnungen immer verändern, er kann aber nicht die angefallenen Punkte einer Belohnung in eine ander "Schütten", sie bleiben auch beim Verschieben einer Belohnung fest zugeordnet. Gedrückt halten einer Belohnung kann die Belohnung löschen. Die Punkte und das maximum sollen immer angezeigt werden. Denk dir ein schickes, übersichtliches aber dennoch minimalistisches Design für diese Listeneinträge aus. Addendum zur Berücksichtigung der Punkte: Es sollen nur Punkte hier reinfließen, die durch das Abschließen von toDos erhalten werden (nicht zB. dadurch, dass Freizeit abgesagt wurde).
