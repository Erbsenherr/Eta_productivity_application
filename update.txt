Features:
-Wochenstatistik. Bei der regulären(!) Wochenplanung soll es einen zusätzlichen Reiter "Wochenrückblick" geben, der dem Nutzer gezeigt wird. Dort bekommt man eine Übersicht über die letzte Woche, in der grobe Infos gegeben werden (wie viele Tasks in der Woche abgearbeitet wurden, wie akkurat alles lief, wie häufig man pünktlich ins bett ging/aufgegangen ist etc... --> und das soll mit der gesamtstatistik verglichen bzw. eingeordnet werden (war man besser? schlechter?)
-Im Debug reiter soll es einen "Balancing" subreiter geben. Dieser soll einen weiteren "Punkte Balancing" subreiter besitzen. Dort sollen alle Punktquellen / Multiplikatoren aufgeführt werden und verändert werden können (Fokuszeit: [], Achtsamkeit: [], Pünktlich schlafen gehen [], Pünktlich aufstehen: [], Task absagen: [], Unverplante zeit: [], etc... --> sodass man die Punktvergabe fine-tunen kann.
-Bearbeitungszeitaufnahme: Bei "gerade" soll es einen kleinen "Stoppuhr" button geben. Wenn man den das erste mal drückt, soll es ein kleines popup geben, dass dessen Sinn erklärt: Wenn man auf die Uhr drückt, beginnt eine Stoppuhr. Der Nutzer soll gefragt werden, ob die Stoppuhr ab Drücken der Uhr, oder rückwirkend mit Beginn der Task laut plan starten soll. Man kann den Timer pausieren und beenden. Wird "beenden" gedrückt, wird gespeichert wie lange man dafür gebraucht hat. Im "Statistiken" Reiter soll es dann ein Submenü geben, in dem alphabetisch sortiert alle Tasks aufgezeigt werden, deren Zeit jemals gestoppt wurde. Wenn man eine dieser Tasks anklickt, wird die durchschnittliche Zeit angezeigt, die man gebraucht hat, das maximum und das minimum. Man kann außerdem alle Zeiten ausklappen und einzelne Zeiten rauslöschen und/oder nachbearbeiten.
-Für Timer tasks: Es soll einen "Vorzeitig beenden" Knopf geben. Wird er gedrückt, öffnet sich ein Fenster, in dem der Nutzer gefragt wird, ob er das wirklich möchte. Standardmäßig werden dann 10% der aktuellen Gesamtzeit von dieser Timer Task entfernt. Das "Vorzeitig beenden" Fenster soll es auch dann geben, wenn der Nutzer eine Timer-Task über die Liste abhakt. Erst, wenn der Nutzer bei der nächsten Instanz dieser Timer-Task diese wieder vollständig (also in der reduzierten Form) absolviert, sollen wieder 2% der ursprünglichen Zeit draufgerechnet werden. Beispiel: Task geht standardmäßig 60 Minuten. Diese wird jetzt nicht vollständig abgeschlossen. Das nächste mal dauert sie 54 Minuten. Werden diese 54 Minuten vollständig absolviert, dauert sie danach wieder 55 min 20 sek. Das geht so lange, bis die Ausgangszeit (60 Minuten) wieder erreicht wurden. Handelt es sich um einen Inkrement timer, wird das Inkrement erst dann draufgerechnet, wenn die Task zu dem Moment (wieder) keinen Zeit-Malus hat (im Falle des Beispiels bei 60 Minuten liegt).
-"Ausnahmesituation" und "Konsequenzen" im "Regeln" Reiter. Konsequenzen sind idR. Notizen. Am Tag des Verstoßes wird im Dashboard (in Rot) angezeigt, dass diese Konsequenz aktiv ist. Man kann die Konsequenz aber auch direkt an den "Freizeit" slot knüpfen: Der Freizeit Slot wird in allen Menüs (gerade, Liste, tagesplanung,...) rot schraffiert, um klar zu machen, dass er unter einer konsequenz liegt. Außerdem wird eine Notiz hinzugefügt, die die Zusatzbedingung definiert ("zB. heute keine Bildschirmzeit").
-"Regelverstoß melden": Es soll einen Button mit einem Ausrufezeichen geben, der sich immer im unteren rechten Bildschirmrand befindet. Wenn dieser gedrückt wird, kann man eine Regel im "Verstoßen gegen..." durch gedrückt halten auswählen. Es wird dann die Konsequenz dieser Regel aktiviert.
-Am Morgen soll es für den Fall, dass es in jüngerer Vergangenheit (zwei Wochen) Regelverstöße gegeben hat, einen kleinen Reminder geben, auf welche Regeln man besonders achten soll. Dieser soll dennoch positiv ausfallen.
-"Ultra-High" Priorität. Wenn eine Task die "Ultra-High" Priority bekommt, dann landet sie direkt im Revolver des aktuellen Tages.

Quality of life:
-Wenn man eine Timer-Task mit Inkrement pro Absolvierung abhakt, die noch nicht bearbeitet wurde, soll der Nutzer gefragt werden, ob es trotzdem zum Inkrement hinzugefügt werden. (Wenn man zb. die Workout Zeit seperat, also nicht über die app trackt, dann soll man trotzdem ein inkrement bekommen können.)
-Wenn eine Task bereits unter einem Konflikt leidet, soll im Berabeitungsfenster dieser Task eine Konfliktlösungshilfe liegen (nach selbem Schema wie bereits an anderen Stellen umgesetzt)
-Wenn "gerade" leer ist, soll durch anklicken von "als nächstes" ein kontextmenü aufgerufen werden, in dem der Nutzer die nächste Task automatisch vorziehen kann.

Bugfixes:
-Anfahrtzeit zu Anfahr-/Vorbereitungszeit und Rückfahrzeit zu Rückfahr-/Nachbereitungszeit ändern.
-Der "Tagesplanung" Notification sound läuft auch noch am nächsten Tag, wenn man die Tagesplanung garnicht mehr abschließen kann.
-Die Reihenfolge bei Routinen zu verschieben ist sehr clunky. Ich kann Subtasks immer nur one-slot-at-a-time verschieben leider sehr unflüssig.
-Wenn das verändern einer Zeit über die "Heute anstehend" Liste in einem Konflikt resultieren würde oder diese Task gerade in einem Konflikt liegt, wird die veränderung nicht gespeichert. Das soll trotzdem geschehen, allerdings soll der Nutzer die übliche Konflikt-benachrichtigung/Anzeige auf dem dashboard bekommen.
