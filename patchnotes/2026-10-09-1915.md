# Eta — Update vom 9. Oktober 2026 (9)

APK: `eta-release-2026-10-09-1915.apk`

## Geändert

### Der Beispieltag im Tutorial ist jetzt ein ganzer Tag
Neben Frühstück, Arbeiten, Katze füttern und Mail versenden enthält der Tag im
Tutorial nun alles, was eine normale Einrichtung ohnehin anlegt: Morgenroutine,
Kochen, Freizeit, Selbstachtsamkeit und Bettfertig machen — dazu dienstags Sport und
samstags Hausputz.

So sieht der Tag aus:

| Uhrzeit | Aufgabe |
| --- | --- |
| 07:00 | Morgenroutine |
| 07:45 | Frühstück |
| 09:00 | Arbeiten |
| 12:00 | Katze füttern |
| 12:30 | Mail versenden |
| 13:00 | Arbeiten |
| 17:15 | Sport (dienstags) · Hausputz (samstags) |
| 18:30 | Kochen |
| 20:00 | Freizeit |
| 21:30 | Selbstachtsamkeit |
| 22:00 | Bettfertig machen |

- Im Tagesabschluss hakt man jetzt **alles außer „Mail versenden"** ab — also auch
  die Aufgaben aus der Einrichtung.
- Die Abrechnung des Beispieltags fällt dadurch **positiv** aus.

## Gut zu wissen

- Damit sich nichts überschneidet, liegen einige Zeiten anders als zuvor: Frühstück
  nach der Morgenroutine, die Mail in der Mittagszeit, Hausputz am Samstagnachmittag.
  Gearbeitet wird vormittags und nachmittags; beide Blöcke heißen „Arbeiten".
- Das betrifft nur das Tutorial. An der eigenen Einrichtung ändert sich nichts.
