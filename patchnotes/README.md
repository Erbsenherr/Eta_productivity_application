# Patchnotes

Für jedes Update eine Datei, geschrieben für die Menschen, die Eta benutzen — nicht
für die Entwicklung. Was sich geändert hat, wo man es findet, und worauf man achten
sollte. Die neueste Datei steht oben, wenn man nach Namen absteigend sortiert.

Dateiname: `JJJJ-MM-TT-HHMM.md`, passend zur APK `eta-release-JJJJ-MM-TT-HHMM.apk`
in `dist/`.
